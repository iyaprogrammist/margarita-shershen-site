# Сайт психолога Маргариты Шершень

Одностраничный сайт гештальт-терапевта Маргариты Шершень: консультации в Москве (м. Боровицкая) и онлайн.

**Сайт:** https://iyaprogrammist.github.io/margarita-shershen-site/

## Структура

- `index.html` — вся страница: разметка, стили и скрипты
- `img/` — фотографии
- `robots.txt`, `sitemap.xml` — для поисковых систем

## Что заменить перед запуском

Телефон и Telegram пока условные. Они заданы в блоке `CONFIG` в конце `index.html`, а также прописаны прямо в HTML и в разметке Schema.org (`"telephone"`, `"sameAs"`).
